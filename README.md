# 🔍 ESP32 Ultimate Network Scanner

[![Platform](https://img.shields.io/badge/platform-ESP32-blue)](https://www.espressif.com/)
[![Framework](https://img.shields.io/badge/framework-Arduino-00979D)](https://www.arduino.cc/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

**ESP32 Ultimate Network Scanner** — это многофункциональный инструмент для сканирования WiFi сетей, подбора паролей (брутфорс), обнаружения устройств в локальной сети и сканирования портов. Всё управление осуществляется через красивый веб-интерфейс с автообновлением.

## 📋 Возможности

| Функция | Описание |
|---------|----------|
| 📡 **WiFi Scanner** | Сканирование всех доступных WiFi сетей с отображением SSID, MAC, RSSI, канала и производителя |
| 🔐 **WiFi BruteForce** | Перебор 30 популярных паролей для выбранной WiFi сети |
| 🌍 **Network Scanner** | Обнаружение всех устройств в локальной сети (IP, MAC, Hostname, производитель) |
| 🔌 **Port Scanner** | Сканирование популярных портов (21, 22, 23, 25, 53, 80, 110, 143, 443, 445, 3306, 3389, 5432, 27017) |
| 📊 **Статистика** | Визуализация данных через графики Chart.js |
| 🚀 **Автообновление** | Автоматическое обновление списка WiFi сетей каждые 5 секунд |
| 🔓 **Captive Portal** | Автоматическое открытие панели управления при подключении |

## 🎯 Что умеет программа

### WiFi Сканер
- Показывает все доступные WiFi сети
- Отображает уровень сигнала (RSSI) в dBm
- Определяет производителя по MAC-адресу
- Показывает канал сети
- Иконки качества сигнала: 🟢 отлично, 🟡 хорошо, 🟠 средне, 🔴 слабо

### WiFi BruteForce
- Перебирает **30 популярных паролей**:
  - `12345678`, `123456789`, `1234567890`
  - `password`, `password123`, `qwerty123`
  - `11111111`, `00000000`... `99999999`
  - `admin123`, `adminadmin`, `root123`
  - `01010101`, `12121212`, `87654321`, `987654321`
- Прогресс-бар в реальном времени
- Оповещение при найденном пароле

### Сетевой сканер
- Сканирует все устройства в локальной сети (1-254 IP)
- Определяет IP, MAC, Hostname
- Распознает производителя устройства
- Сканирует открытые порты на каждом устройстве

### Порт сканер
- База из **14 популярных портов**
- Отображение названия протокола
- Статус порта (открыт/закрыт)

## 📥 Установка

### 1. Установка Arduino IDE и ESP32

```bash
# Откройте Arduino IDE
# Файл → Настройки → Дополнительные ссылки для менеджера плат:
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json

# Инструменты → Плата → Менеджер плат → установите "ESP32 by Espressif Systems"
```

### 2. Установка библиотек

Через менеджер библиотек (Скетч → Подключить библиотеку → Управлять библиотеками):

| Библиотека | Версия | Для чего |
|------------|--------|----------|
| ArduinoJson | 6.21.0+ | Работа с JSON |
| DNSServer | встроенная | Captive Portal |
| WebServer | встроенная | Веб-сервер |
| WiFi | встроенная | WiFi функции |

### 3. Загрузка кода

```bash
# Клонируйте репозиторий
git clone https://github.com/AnonimusShamshiAlex/esp32webwifi-tool

# Откройте файл ESP32_Network_Scanner.ino в Arduino IDE
# Выберите плату: Инструменты → Плата → ESP32 → ESP32 Dev Module
# Выберите порт: Инструменты → Порт → COMx (Windows) / /dev/ttyUSBx (Linux)
# Нажмите Загрузить (стрелка →)
```

## ⚙️ Настройка

### Изменение имени и пароля точки доступа

В файле `.ino` найдите строки:

```cpp
const char* ap_ssid = "ESP32_Radar";
const char* ap_password = "shamshi006";
```

Измените на свои значения.

### Добавление своих паролей для брутфорса

Найдите массив `commonPasswords`:

```cpp
const char* commonPasswords[] = {
  "ваш_пароль1", "ваш_пароль2", ...
};
```

### Изменение портов для сканирования

В массиве `commonPorts`:

```cpp
PortInfo commonPorts[] = {
  {порт, "Название", "Описание"},
  ...
};
```

## ❗ Известные ограничения

1. **Ограничение брутфорса:** ESP32 может перебирать только пароли из заданного списка
2. **Скорость сканирования:** Между попытками есть задержка 3 секунды
3. **Память:** Большое количество устройств может замедлить работу
4. **Определение MAC по IP:** Функция `getDeviceMAC` возвращает заглушку (требуется ARP)

## 🔧 Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Не вижу сеть ESP32_Radar | Перезагрузите ESP32 кнопкой RST |
| Страница не открывается | Проверьте IP: `http://192.168.4.1` |
| WiFi сканер показывает 0 сетей | Перезагрузите ESP32, повторите сканирование |
| Брутфорс не работает | Убедитесь, что целевая сеть в зоне доступа |
| Ошибка компиляции | Установите библиотеку ArduinoJson 6.x |
